## 这是什么

一套为**包租公/包租婆/二房东/物业管家**设计的轻量收租台账。把「签合同 → 每月出账 → 催租收款 → 押金管理 → 经验沉淀」整条链路搬进浏览器：手机拍着租客房门就能记账，电脑上对着账单批量结清，数据全部存在你自己的 MySQL 里。

PHP 版是同系列的**第三种部署形态**：HTML 版负责「零安装本地用」，Docker 版负责「重度自托管」，PHP 版负责「**几块钱甚至免费的虚拟主机，随时随地跨设备访问**」。

## 功能清单

- **房产管理**：多物业、多房间，面积/默认租金/归档状态
- **租客档案**：电话、证件、备注
- **租约全周期**：起租/到期、房屋押金与水电押金分开、付款日、月付/季付、租金递增（按比例/按金额）、生效/失效状态
- **账单自动化**：按周期自动生成、逾期天数实时计算、杂费明细、手工补录、账单图片
- **收款管理**：部分收款/批量结清、多种收款方式、收款记录留痕
- **经验库**：签约、退租经验按租约沉淀，新人也能接手
- **多用户与权限**：管理员/普通用户、功能授权、停用账号、改密
- **报表**：按物业 → 按月份汇总，12 个月翻页
- **数据安全**：JSON 快照备份与恢复

## 技术架构

```
浏览器（单页 index.php，原生 JS，无框架）
        │  fetch REST  JSON（同签名 DB 适配器）
        ▼
api.php（单文件路由：16 个 action，PDO 预处理 + PHP Session）
        ▼
MySQL 8 / MariaDB（10 张 InnoDB 表，utf8mb4）
```

- PHP **8.0+**（演示环境 PHP 8.4 / MariaDB 11.4 验证通过）
- 无任何第三方依赖，开箱即跑
- 表/列命名与前端对象属性一一对应，维护成本低

## 30 秒安装（以 InfinityFree 等 cPanel 虚拟主机为例）

1. 在主机控制面板 **MySQL Databases** 里新建一个数据库（记下主机名、库名、用户名、**数据库密码**）
2. 把本项目全部文件上传到网站根目录（一般是 `htdocs/`）
3. 浏览器访问 `https://你的域名/setup.php`
4. 表单填入数据库信息和管理员账号密码，点「测试连接并开始安装」
5. 看到 ✅ 安装成功后，删除服务器上的 `setup.php`，打开 `index.php` 登录即可

> 安装向导会自动生成 `config.php`（该文件已在 `.gitignore` 中，永不入库）。
> 不想用向导？可手动复制 `config.sample.php` 为 `config.php` 填好信息，再导入 `schema.sql`。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.php` | 前端单页应用（含登录页） |
| `api.php` | 后端 API 单文件路由（鉴权 / CRUD / 备份导入导出） |
| `setup.php` | 网页安装向导（安装完建议删除） |
| `schema.sql` | 数据库表结构（向导自动读取执行） |
| `config.sample.php` | 配置模板（手动部署时用） |
| `.htaccess` | Apache 安全规则（禁访配置与结构文件、关目录列表、安全响应头） |

## 安全建议

- 安装后立即删除 `setup.php`，并在「设置」中修改默认管理员密码
- `config.php` 包含数据库密码，**不要**提交到任何代码仓库
- 请为主机开启 HTTPS（大多数免费主机支持一键 SSL），会话 Cookie 会自动跟随 Secure 策略

## 数据备份与迁移

数据全部保存在服务器 MySQL（10 张业务表 + 键值设置表），备份/恢复功能在应用内「设置 → 💾 数据备份与恢复」，**仅总管理员可用**，页面上有同样的说明文字。

**方式一：页面 JSON 快照（推荐，零命令）**

1. 登录后进入「设置」，点「🚀 一键备份」或「⬇️ 导出 JSON」，浏览器下载 `物业管理台账备份-日期时间.json`
2. 备份内容：物业 / 房间 / 租客 / 租约 / 账单 / 杂费 / 收款 / 经验 / 账号（bcrypt 哈希）/ 全部设置（含收款码），不含数据库连接密码
3. 恢复：点「⬆️ 从备份恢复」选择 JSON，确认后服务端在**单个数据库事务**内清空并整体覆盖写入，中途失败自动回滚，不会留下半份数据
4. 该格式与 **HTML 单文件版完全互通**（`app: property-ledger-html`，version 1.4）：HTML 版导出的 JSON 可直接导入本版上线，反之亦可

**换主机迁移流程**：旧站点导出 JSON → 新主机上传 5 个文件并跑完网页安装向导 → 登录新站点「从备份恢复」选择 JSON → 数据、账号、收款码全部还原，全程不用手动操作数据库。

**方式二：整库灾备（可选）**

- cPanel 主机：phpMyAdmin → 选择本库 → 导出 → SQL 格式下载；恢复时新建空库后导入
- 命令行：`mysqldump -u 用户名 -p 库名 > backup.sql` 备份，`mysql -u 用户名 -p 库名 < backup.sql` 恢复

> 注意：备份 JSON 含登录密码哈希，请像钥匙一样妥善保管（网盘 / U 盘），不要公开分享。
